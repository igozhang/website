# Websphere-Was手动发版

## 部署

1. 登录管理后台  
   https://$ip/ibm/console
2. 立即停止所有服务  
   服务器>集群>Websphere Application Server 集群 >立即停止
3. 删除应用程序  
   应用程序2全部应用程序2除去2成功卸载（保存）2全部应用程序>与节点同步更改(确定)
4. 添加新应用程序  
   应用程序2新建应用程序(新建企业应用程序)2准备应用程序安装，新应用程序的路径（上传）下一步2准备应用程序安装，您想如何安装此应用（快速路径）下一步
5. 指定可用于应用程序的各种选项  
   需填写（应用程序名）  
   需勾选（分发应用程序，为资源创建MBean）
6. 指定用于安装企业应用程序的模块和选项  
   集群和服务器（选择所有集群和服务器并点击应用）2勾选模块2下一步
7. 为Web模块映射上下文根  
   填写正确的上下文跟（访问路径，类似于nginx\_location，exp：/igofiles）
8. 摘要  
   检查各配置项，没问题点完成2确定

## 配置

1. 常规属性\_类装入和更新检测  
   应用程序2全部应用程序2点击应用程序（exp：igowar）2类装入和更新检测2确定2保存  
   被填充或选择项（其余为未被填充或勾选）

- 类已装入并且是先使用本地类装入器（父类最后）
- 应用程序中每个WAR文件的类装入器

1. 节点同步  
   系统管理2节点2选择所有节点2全部再同步
2. 启动  
   服务器2所有服务器2选择一个节点2启动
3. 验证  
   等几分钟启动成功后可访问  
   http:$ip/上下文根
