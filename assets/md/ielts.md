## 第1-2个月：

深入了解雅思考试：  
了解雅思考试全貌，包括考试科目、知识点和分值。  
研究不同考试形式，例如听力、阅读、写作和口语，以此制定备考计划。  
评估自己的英语水平：

参加模拟考试或者咨询专业机构或老师进行水平评估。

英语基础知识学习：  
阅读相关教材、参加雅思培训课程，提高英语语法、词汇、语音等方面的知识点。  
每日积累词汇，掌握常用短语、搭配表达。

## 第3-4个月：

技能练习：  
每天进行听力、阅读、写作和口语的练习。  
收听英语新闻、观看电影，提高听力技能。  
阅读英语文章，为阅读和写作积累素材。

雅思题型熟悉：  
研究雅思各科目的题型，熟悉解题技巧。  
定期进行雅思模拟题的练习。

## 第5个月：

专项训练： -针对个人的薄弱环节进行专项训练，如听力的同步速度、口语的发音和语流、写作的逻辑和论据、阅读的速度和理解能力等。

模拟考试与分析：  
定期参加模拟考试，了解自己的备考水平。  
针对模拟考试结果进行自我分析，针对性地提各部分的力。

## 第6个月：

整体提升：  
整合所学知识，强化综合技能。  
继续参加模拟考试，根据成绩调整备考策略。  
考前冲刺：  
熟练掌握时间分配和压力管理。  
复习重点知识点，巩固记忆。

考前心理调整：  
保持充足的睡眠和良好的生活习惯。  
保持积极心态，增强信心。

## Tips

### 雅思考试内容

1. 听力：1个小时，4个部分Section1~S4，每部分10道题，题型主要有填空，选择，配对，地图流程题；答题时间为30+10min；
2. 阅读：1个小时，40题，3篇文章每篇10~14题，题型主要有判断，配对，选择，填空；答题时间为20X3=60分钟
3. 写作：1个小时，小作文看图写作要求150字，大作文主题议论文250字；
4. 口语：15~20分钟，Part1日常交谈（天气，城市，兴趣爱好）；P2看话题卡片及要求，说1~1.5分钟；P3继续P2话题延申

### 雅思考试注意事项

1. 报名： ielts.etest.edu.cn 注册交钱选考位，建议提前1~2个月报，一般考试提前10天能考到考场安排；
2. 材料： 身份证，白底近照X2；
3. 口语考试前会采集图像，用作成绩单；
4. 考完10天左右出成绩；

### 雅思考试心得

1. 练习时使用雅思考试答题纸，铅笔；答题纸可以网上下载自己打印；
2. 认真钻研剑8；

### 雅思计分规则

9分制

| 分数 | 说明 |
| --- | --- |
| 9分 | 能做到适当、精确、流利地运用英语能力，并能完全理解语言。 |
| 8分 | 能熟练运用英语，只有极少的错误。在不熟悉语境下可能出现误解，可将复杂细节的争论掌握好。 |
| 7分 | 能有效运用英语，偶尔出现不准确、不适当或误解。能掌握复杂的英语，理解详细的推理。 |
| 6分 | 能较为有效运用英语，虽然有不准确、不适当和误解，但能在熟悉的语境下理解复杂的英语。 |
| 5分 | 可部分运用英语，在多数情况下明白大体意思。虽然经常出现错误，但能在熟悉领域内做基本沟通。 |
| 4分 | 只限在熟悉的语境下有基本的理解力，在理解与表达上常发生问题，不能使用复杂英语。 |
| 3分 | 在非常熟悉的语境下只能做简单的沟通，有频繁的沟通障碍。 |
| 2分 | 非熟悉的语境不能进行有效沟通。难以听懂或者看懂英语。 |
| 1分 | 无法用英语沟通。 |
| 0分 | 缺乏评分依据。 |
